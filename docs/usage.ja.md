# 使い方

[English](usage.md) | 日本語

サーバが動いていて端末のペアリングが済んだ状態（[getting-started.ja.md](getting-started.ja.md)）
からの、even-window の使い方です。グラスにはミラーデスクトップが映り、グラスのジェスチャと
スマホ画面で操作します。

## グラスのジェスチャ

ジェスチャは左右どちらのテンプルからでも、リングからでも送れます。

| ジェスチャ | ミラー表示中 | メニュー表示中 |
| --- | --- | --- |
| 上 / 下スワイプ | フォーカス中のウィンドウにキーを送る。既定は `Up` / `Down`。アプリケーションごとに変更可能 | カーソルを動かす（端で反対側に回る） |
| タップ | `Return` を送る | 行を選ぶ |
| ダブルタップ | メニューを開く | 1 階層上へ。最上位ではメニューを閉じる |
| 長押し | 音声入力を始める（認識サービスが設定されているとき） | — |

短い間隔で続けたスワイプは 1 つのバッチにまとめて送られます。5 回続けてスワイプすれば、
キーが 5 回押されます。

最初の数回の起動時には、これらのジェスチャの一覧がレンズに表示されます。一覧は
ジェスチャをするまで消えません。どの
ジェスチャでも閉じられ、ダブルタップならそのままメニューも開きます。

## グラス上のメニュー

ダブルタップで開きます。メニューが出ている間はミラーは隠れ、メニューを閉じると戻ります。

最初の階層（見出しは `Tasks`）には、次の順で行が並びます。

- `Menu...` — それ以外のすべてへの入口。メニューを開いた直後はここにカーソルがあります
- 開いているウィンドウ（最後にフォーカスした順）— タップでそのウィンドウに切り替え。
  タイトルが短いときは `~ (XTerm)` のようにアプリケーション名が続きます
- `+` で始まる行: 最近起動したアプリケーション（最大 8 件）— タップで起動

パネルに出るのは見出しと 9 行（`Menu...` と、ウィンドウ・`+` の行を合わせて 8 行）です。
ウィンドウと `+` の行が合わせて 8 個を超えると、一覧はウィンドウを先にして 8 個ずつの
ページに分かれ、見出しにページ番号（`Tasks 1/2`）が出ます。場所が足りないために `+` の行が
消えることはありません。それ以外のアプリケーションは `Menu...` → `Launch...` と、スマホの
**apps** パレットにあります。

ページが複数あるとき、先頭行は `Menu/Prev/Next...` になり、その下の階層の
末尾に `Prev Page` と `Next Page` が加わります。選ぶと隣のページの一覧に戻り
（端では反対側へ回り込みます）、カーソルは再び先頭行にあります。タップ、上スワイプ、
タップで次のページに進めます。

`Menu...` の下:

| 行 | 用途 |
| --- | --- |
| `Keys...` | スワイプでは表せないキーを送る: 修飾キー、移動・編集キー、ファンクションキー、文字、マウスのクリックとホイール |
| `Window...` | ウィンドウマネージャの操作: 次・前・直前のウィンドウ、新しいターミナル、再描画、キーのヘルプ、`Kill (force)` |
| `Launch...` | 任意のアプリケーションを起動する: 全件を名前順に並べる。9 件までは直接並び、それを超えるとページに分かれ、各行が範囲とページ内の名前の先頭を示す（例: `Fi-Gn (Files\|Firefox\|GIMP\|Gnome Te)`） |
| `Invert` | 明暗を反転する |
| `Close Window` | フォーカス中のウィンドウに閉じるよう求める |
| `Exit...` | 確認の行を経て、グラス上のアプリを終了する |
| `Prev Page` / `Next Page` | ページが複数あるときだけ末尾に出る: 最初の階層のページを送る |

ダブルタップで 1 階層戻り、最初の階層ではメニューを閉じます。`< Back` の行があるのは
確認の階層（`Exit...`、`Kill (force)...`）だけです。

操作を選ぶと、結果が見えるようにメニューは閉じます。`Keys...` の下の行を選んだあとは、
次のダブルタップで同じ場所にメニューが開き直すので、キーを繰り返し送るのが楽になります。

## スマホ画面

スマホ画面はグラスを見なくても使えます。大半はグラスが繋がっていなくても動きます。
初めて接続したときに短いツアーで画面を案内します。タイトル行の **?** でいつでも見直せます。

| コントロール | 用途 |
| --- | --- |
| **task** | ウィンドウの切り替え。全ウィンドウを、タイトル全文で、最後にフォーカスした順に表示 |
| **window** | `Window...` の操作と `Close Window` を、グラスを使わずに行う。`Kill (force)` は 2 回タップが必要 |
| **apps** | アプリケーションの起動。フィルタ欄つきの全件一覧と **rescan** |
| プレビュー | ミラーのライブ表示。タップでクリック、ドラッグで押したまま移動（左ボタン）。グラスがメニューや音声ダイアログを表示している間は、その文字を表示します。 |
| テキスト欄、**Submit** | フォーカス中のウィンドウに文字を入力する。下記参照 |
| **voice** | スマホから音声入力を始める。認識サービスが設定されているときだけ表示 |
| **▼ dn**、**▲ up**、**● tap**、**●● dbl** | グラスと同じ 4 つのジェスチャ |
| **font −**、**font +** | フォーカス中のアプリケーションの文字を小さく／大きくする |
| **keys** | オンスクリーンキーボード: 修飾キー、ナビゲーションキー、QWERTY 配列 |
| **vRing** | 全画面のジェスチャパッド: どこでも縦スワイプ、左半分のタップでタップ、右半分のタップでダブルタップ。音声入力が使えるときは、下端の帯のタップで長押し |
| **vPad** | 全画面のトラックパッド: ドラッグで移動、タップでクリック、長押しで押したままドラッグ、2 本指ドラッグか右端の帯でホイール、左／中／右ボタンの選択、もう一度タップするまで効き続ける Ctrl / Alt / Shift のトグル |
| **inv** | 明暗を反転する |
| **color** / **green** | プレビューの描き方: デスクトップの色のまま、またはグラスに映る見た目 |
| **lens** | グラスの表示を一時停止・再開する |
| **app** | アプリケーションごとの割り当て |
| **connection** | サーバの URL、接続状態、ペアリング、登録済み端末の一覧 |
| **log** | クライアントのログ（コピー可能） |

スマホとペアリングしたハードウェアキーボードは、ページ上のテキスト欄にフォーカスが
無いとき、フォーカス中のウィンドウに入力されます。

### テキストを送る

テキスト欄に入力して **Submit** をタップするか、欄の中で `Ctrl+Enter` を押します。文字が
フォーカス中のウィンドウに入力され、続いてそのアプリケーションの **submit** キーが
押されます。既定の submit キーは `off` です。つまり文字は入力されますが、何も実行
されません。Submit でその行を実行したいアプリケーションでは、一度設定してください
（[アプリケーションごとの割り当て](#アプリケーションごとの割り当て)）。最初の数回は、
submit キーなしで入力されたときに、この設定の場所をトーストで知らせます。

submit キーなしで 1 回だけ送るには、ボタンが反転するまで **Submit** を押し続けてから
離します。離す前に指をボタンの外へ滑らせると取り消しになります。

## 切り替え・終了・起動

| 作業 | グラス | スマホ |
| --- | --- | --- |
| ウィンドウを切り替える | ダブルタップしてウィンドウを選ぶ | **task** |
| ウィンドウを閉じる | `Menu...` → `Close Window` | **window** → `Close Window` |
| 強制終了する | `Menu...` → `Window...` → `Kill (force)`、続けて確認 | **window** → `Kill (force)` を 2 回タップ |
| 起動する | ダブルタップして `+` の行を選ぶ。または `Menu...` → `Launch...` | **apps** |
| 新しいターミナル | `Menu...` → `Window...` → `New terminal` | **window** → `New terminal` |

どのウィンドウも画面全体を占めます。タイル配置やサイズ変更はありません。ランチャに並ぶ
ものを変えるには [`apps.conf`](configuration.ja.md#appsconf) を編集します。

## アプリケーションごとの割り当て

スマホで **app** を開きます。折りたたんだ見出しには、フォーカス中のウィンドウにいま
効いている割り当てが表示されます。

1. **app** — 割り当てを何に結び付けるかを選びます。一覧には、フォーカス中のウィンドウが
   持つ身元がすべて、種類のラベル（バイナリ、プロセス名、ウィンドウクラス、ランチャの項目）
   つきで並びます。最初から選ばれているのは、そのプログラムをどこから起動しても追従する
   ものです。すべてのアプリケーションの既定を決めるには `*` を選びます。
2. **▲ up**、**▼ dn** — それぞれのスワイプが送るキー。一覧から選んだキーに `Ctrl`、`Alt`、
   `Shift` のトグルを組み合わせるか、`wheel up` / `wheel down` を選びます。ページャには
   `Page_Up` / `Page_Down`、vim には `Ctrl+u` / `Ctrl+d`、Web ページにはホイールが合います。
3. **submit** — **Submit** が本文のあとに押すキー。シェルなら `Enter`、多くの Web フォーム
   なら `C-Enter`、ほかに `Tab` や `off`。
4. **newline** — 本文中の改行が何になるか。`Enter` で送信されてしまうチャット欄では
   `S-Enter` を使います。
5. **fontsize** — **font −/+** が押すキー。既定は xterm 向けで、ほかの選択肢はブラウザや
   一般的なターミナルに対応しています。
6. **apply**。**clear** は割り当てを外し、そのアプリケーションは再び継承に戻ります。

スワイプは繰り返されます。スワイプに `Return` を割り当てると、5 回のスワイプで 5 つの
コマンドが実行されます。そのような割り当てをすると、パネルが警告します。割り当ては
[`bindings.json`](configuration.ja.md#bindingsjson) に保存されます。

## 音声入力

サーバに認識サービスが設定されているときに使えます
（[セットアップ](getting-started.ja.md#任意-音声認識)）。音声は自分の PC 上で認識され、
フォーカス中のウィンドウに入力されます。

1. グラスを長押しするか、スマホの **voice** をタップします。
2. 話し終えたらタップして止めます（スマホでは **stop**）。録音は 30 秒で自動的にも
   止まります。
3. グラスに認識結果と `Send`、`Again`、`Cancel` が表示されます。スワイプで選び、タップで
   決定します。ダブルタップはどの段階でも取り消しです。6 行を超える認識結果はページに
   分かれます（ヘッダに `1/3` と出ます）。タップか下スワイプでページを送ります。`Send`、`Again`、
   `Cancel` は最後のページにだけ出ます。最後のページに入った時点ではどの行も選ばれて
   おらず、もう一度タップか下スワイプをすると `Send` にカーソルが出ます。上スワイプで
   戻ります。`Send` は全文を送ります。
4. 認識結果はスマホのテキスト欄にも入るので、編集してから **Submit** をタップしても
   かまいません。`Cancel` は欄も空にします。ダイアログは 60 秒操作がなければ自動的に
   閉じます。

`Send` は **Submit** と同じ動作で、アプリケーションの submit キーも押されます。

使われるのはグラスのマイクです。グラスを接続せずにアプリを起動した場合は、代わりに
スマホのマイクが使われ、ダイアログはスマホのプレビューにだけ表示されます。仕組みは
[voice.md](voice.md) にあります。

## ミラーを一時停止する

ミラー中はレンズが発光し続け、無線リンクも使い続けます。グラスを休ませるには:

- **lens:on** — タップで一時停止します。更新が止まってレンズが暗くなり、グラスには再開に
  使うコントロールを示す短い通知が出ます。ボタンの表示は **lens:off** になり、タップで
  再開します。停止中もスマホは使えます。一時停止の状態は、アプリを起動し直すと
  引き継がれません。
- **ケースの中。** グラスをケースに入れるとミラーは一時停止し、取り出すと再開します。
  ボタンの表示は **lens:case** になります。センサが誤っているときはタップしてください。
  そのセッションの間、ケースのセンサは無視されます。

グラスを外してもミラーは一時停止しません。装着センサは信頼できなかったため、使って
いません。

## 明暗

グラスは光学シースルーで、自ら発光する表示です。黒は透明になり、明るい画素が光ります。
暗い背景に明るい文字がもっとも読みやすく、消費電力も少なくなります。既定のターミナルが
暗いのはそのためです。

スマホの **inv**、またはグラスのメニューの `Invert` は、明るいテーマしか持たない
アプリケーションのために明暗を反転します。この設定は端末に記憶されます。
