# ステータス

[English](status.md) | 日本語

成熟度: 概念実証（PoC）。バックエンドは 1 つ（Linux）です。ミラー、ジェスチャ、ウィンドウ
切り替え、音声入力は実機の G2 で動作します。このページは各機能をどこまで検証したかの
記録です。それぞれの仕組みはリファレンスのドキュメントにあります。

## 検証レベル

| レベル | 意味 |
| --- | --- |
| 実機（G2） | 実機の G2 グラスで確認した |
| 実機（iPhone） | 実機の iPhone 上の Even App で確認した |
| シミュレータ | Even Hub シミュレータで end-to-end に確認した。実機では未確認 |
| 撤去 | 実機で動かない、または当てにならないと分かり、取り除いた |
| 未検証 | コードの経路はあるが、通したことがない |

## 既知の制限

- **再接続は未検証です。** グラスを掛け外ししてもリンクは切れないため、リンクが切れた
  あとにミラーを復帰させる経路を実機で通せていません。
- **Bluetooth の切断直後に Even App が終了することがあります。** 原因は特定できて
  いません。pinhole-window とは無関係だと考えていますが、確証はありません。2026-11-23 にも、
  アプリの実行中に Bluetooth を切ったときに再現しました。
- **そのようなクラッシュの前に見られた、WebKit の未捕捉の `NotSupportedError` は原因不明
  です。** これが引き金になっていたログの洪水は pinhole-window 側のバグで、修正済みです。
- **グラスを外しても自動では一時停止しません。** `isWearing` は信頼できません。**lens**
  ラッチかケースを使ってください。
- **スマホの全画面パッドでのプラットフォームのタッチ既定動作の抑止は、シミュレータでは
  確認できません。**
- **Bluetooth キーボードの矢印キーは iOS の WebView に届きません。** Web の層からは
  直せません。
- **右クリックは vPad でのみ使えます。** プレビューにはダブルクリック専用の経路が
  ありません。
- **カラーも滑らかな動画もありません。** グラスは 4 ビットグレーで、タイルの更新 1 回に
  およそ 75 ms 以上かかります。
- **Linux のみです。**
